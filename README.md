# IFRS Calculator

A web-based calculator for IFRS/IAS computations, organized by chapter.

## Structure

- Left sidebar with chapter bookmarks (IAS/IFRS chapters)
- Each chapter on its own page with relevant calculators

## Planned Chapters

- **IAS 2** — Cost absorption, inventory calculators (periodic, perpetual, FIFO, LIFO, average method)
- More to come...

## Tech

Pure frontend: HTML, CSS, JavaScript. No build step, no dependencies.
